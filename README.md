# Sistema POS - Ferretería CMA

Este es un sistema de Punto de Venta (POS) y gestión de inventario diseñado a medida. El sistema permite agilizar las ventas diarias, llevar un control riguroso del inventario, gestionar clientes, y administrar accesos y privilegios de usuarios.

---

## 🛠️ Tecnologías Utilizadas

### Backend
*   **Laravel:** Framework robusto para la lógica del servidor, API y seguridad.
*   **Base de datos:** Relacional (MySQL / PostgreSQL según la configuración en `.env`).

### Frontend
*   **React:** Biblioteca para construir la interfaz de usuario interactiva y de alto rendimiento.
*   **Inertia.js:** Para conectar Laravel y React de forma fluida sin la complejidad de una SPA tradicional.
*   **Vite:** Herramienta de compilación rápida para el frontend.
*   **Tailwind CSS & Headless UI:** Estilizado moderno y componentes accesibles.
*   **Zustand:** Manejo de estado global en el lado del cliente.
*   **ECharts:** Creación de gráficos interactivos y dinámicos para los reportes.

---
